# Coaching notes · 练习指导

These notes adapt the upstream themes of groove, muting, relaxed effort, repertoire, and tracking. They are general practice guidance, not a validated curriculum or an examination standard. When recommending a specific external lesson, verify its source instead of inventing a citation.

这里延续原项目的节奏、制音、放松、曲目和记录主题，属于一般练习指导，不是经过认证的课程或考试标准。推荐具体课程时核对来源，不编造引用。

## Useful terms · 常用术语

| 中文 | English | Practical focus / 练习重点 |
| --- | --- | --- |
| 二指交替 | Alternating fingers | Consistent sound and relaxed motion / 声音均匀、动作放松 |
| 制音、闷音 | Muting | Control strings that should be silent / 控制不该发声的弦 |
| 律动 | Groove | Timing, rests, accents, and note length / 时机、休止、重音和音长 |
| 音符长度 | Note length | Deliberate note endings / 有意识地控制收音 |
| 闷音节奏音 | Ghost note | Muted percussive sound / 闷住音高的打击性声音 |
| 底鼓 | Kick drum | Rhythm reference in the arrangement / 编曲中的节奏参照 |
| 八分音符 | Eighth notes | Two notes per beat in a simple quarter-note pulse / 以四分音符为一拍时每拍两个 |
| 十六分音符 | Sixteenth notes | Four notes per beat in a simple quarter-note pulse / 以四分音符为一拍时每拍四个 |
| 击弦与勾弦 | Slap and pop | Coordinated impact, release, and muting / 击弦、释放与制音配合 |

## Technique decisions · 技术判断

- Fingerstyle: begin with comfortable curved fingers and a small, relaxed stroke. A rest stroke may land on the adjacent lower-pitched string where appropriate. Do not mandate rigid straight fingertips or a claw shape; the useful check is even sound without excess tension. / 指弹可从自然弯曲、幅度小而放松的动作开始，适合时可用靠弦拨法。不要强迫指尖僵直或刻意抓成爪形；重点是均匀声音和没有多余紧张。
- Fretting: use enough pressure for a clean note, usually near the fret without sitting on it. Check setup if clean sound consistently requires unusual force. / 左手以干净发声所需的压力为准，通常靠近品丝而不直接压在品丝上；如果总要异常用力，应检查琴的设置。
- Muting: inspect which string rings and coordinate both hands. A fixed anchor, moving anchor, or floating thumb can all be appropriate; choose by the instrument and task, not string count alone. / 先找出哪根弦在响，协调双手。固定支点、移动支点、浮动拇指都有适用场景，不能只凭弦数定唯一手型。
- Groove: include rests and note endings. Use a metronome or drum pattern when working on timing; free exploration can have a different purpose. Locking with the kick is a useful starting point, not a rule that every bass note must duplicate the kick. / 把休止和收音也当成练习内容。节奏练习可用节拍器或鼓机，自由探索可以有其他目的；与底鼓配合很有用，但不要求每个音都照抄底鼓。
- Slap: distinguish rebound-oriented strokes and through-string strokes, including double-thumb contexts. Do not present either as the only correct method. Start slowly, attend to muting and consistent sound, and clarify which stroke the learner is attempting. / Slap 有回弹式和穿弦式等动作，双拇指也有自己的语境；不要把某一种说成唯一正确。慢速练制音与均匀声音，先明确用户练的动作。
- Tone: identify the instrument, amp/interface, room, and arrangement before suggesting EQ. No universal "cut mids" prescription. / 音色问题先了解琴、音箱/声卡、房间和编曲，不能统一建议削中频。

## Small drills · 小练习

Choose one or two drills based on the current difficulty. State a comfortable starting tempo or let the learner choose one; label any proposed tempo as a suggestion. Keep time spent exploring separate from demonstrated benchmarks.

按当前困难选一两个练习。起始速度以舒服为准，建议速度要标成建议，不能作为已经达到的成绩。

1. Even alternating fingers: one open string, four bars at a chosen subdivision, then rest. Listen for consistent volume and check relaxation. / 二指均匀：单根空弦，在选定细分下弹四小节后休息，注意音量均匀和放松。
2. String changes and muting: alternate a short pattern between two adjacent strings slowly. Stop unwanted ringing without squeezing harder. / 换弦与制音：在两根相邻弦上慢速重复短句，控制杂音而不是不断加力。
3. Note endings: play the same simple pulse with short then longer notes; keep the starts aligned and make the endings deliberate. / 收音：同一个简单节奏分别弹短音和长音，保持起音一致，有意识地控制结束。
4. Groove with drums: use a simple beat, play a sparse line, and identify where notes support or contrast the kick. / 跟鼓律动：用简单鼓点弹稀疏的低音句，听清哪些音与底鼓呼应或形成对比。

When reviewing audio or video is supported, state the segment inspected and the actual evidence. Without inspection, describe likely causes as possibilities and give a check the learner can perform. / 当前工具支持分析媒体时，说明实际查看的片段和依据；没有查看时，把原因写成可能性，并给用户可自行验证的方法。
